# 이동호 포트폴리오

Python 백엔드 개발자 이동호의 경력과 수행 프로젝트를 정리한 포트폴리오입니다.

## 수록 내용

- Python 웹 백엔드, 비동기 작업 시스템 및 데이터 저장 구조 개발 경력
- 혜움랩스 개발 경력 및 주요 프로젝트 6건
- 프로젝트별 수행 업무, 확인 가능한 결과, 기술 스택
- 기술 및 학력

## 로컬 실행

```bash
npm install
npm run dev
```

배포용 빌드는 `npm run build`로 확인할 수 있습니다.

## 기술

Next.js, React, TypeScript, Vinext, Tailwind CSS
