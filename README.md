# 이동호 포트폴리오

회계·세무 도메인 경험을 바탕으로 자동화, 스크래핑, 비동기 처리 시스템과 AI 에이전트를 개발해 온 Python 백엔드 엔지니어 이동호의 포트폴리오입니다.

## 주요 내용

- 9년 이상의 Python 개발 경험
- 세무 정보 스크래핑 처리 시간 약 62.5% 단축
- SmartA·세무사랑 ERP 자동화
- 세무 신고 및 금융 데이터 수집 시스템
- 내부 CS·운영 지원 AI 에이전트
- Django 백엔드, Celery 비동기 작업, AWS 인프라 운영

## 로컬 실행

```bash
npm install
npm run dev
```

배포용 빌드는 `npm run build`로 확인할 수 있습니다.

## 기술

Next.js, React, TypeScript, Vinext, Tailwind CSS
